# Door 404 — escaperoom.co.rs

Version control for custom WordPress code used by [escaperoom.co.rs](https://www.escaperoom.co.rs/).

## Scope

Track only code that we own:

- child theme customizations
- the `door404-site-tools` plugin
- deployment and verification scripts
- technical documentation

Do not commit WordPress core, the database, uploads, caches, backups, logs, or credentials.

Live pages, posts, media, and SEO metadata remain managed through the WordPress REST API. Production deployment is not connected yet; repository changes must not be treated as live until deployment is explicitly configured and verified.
